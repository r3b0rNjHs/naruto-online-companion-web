## English

### What this repository is

This repository only hosts the **web version** (GitHub Pages). It is the same app as the Windows one, with the same data and the same updates. Everything else — what the app does, screenshots, FAQ — is on the main page: **[noc-releases](https://github.com/r3b0rNjHs/noc-releases)**.

| You use | Go to |
|---|---|
| Windows 10/11 | **[noc-releases → Releases](https://github.com/r3b0rNjHs/noc-releases/releases/latest)** (installer) |
| Android, iPhone, Mac or any browser | **[The web app](https://r3b0rnjhs.github.io/naruto-online-companion-web/)** |

### Install it on your phone or Mac

Open **[the web app](https://r3b0rnjhs.github.io/naruto-online-companion-web/)**, then:

- **Android (Chrome):** menu ⋮ → **Install app** (or *Add to Home screen*).
- **iPhone (Safari):** Share button → **Add to Home Screen**.
- **Mac:** Safari → File → **Add to Dock**; Chrome or Edge → the install icon in the address bar.

Once installed it opens like an app and also works offline. It updates itself every time you open it online.

### Your data

- Everything you note is stored **only on that device**, in the browser. No accounts, no servers.
- To move your data between your PC and your phone: *Settings → Backup* (copy on one, restore on the other).
- It doesn't touch the game: you note what you own.

## Español

### Qué es este repositorio

Este repositorio solo aloja la **versión web** (GitHub Pages). Es la misma app que la de Windows, con los mismos datos y las mismas actualizaciones. Todo lo demás —qué hace la app, capturas, preguntas frecuentes— está en la página principal: **[noc-releases](https://github.com/r3b0rNjHs/noc-releases)**.

| Usas | Ve a |
|---|---|
| Windows 10/11 | **[noc-releases → Releases](https://github.com/r3b0rNjHs/noc-releases/releases/latest)** (instalador) |
| Android, iPhone, Mac o cualquier navegador | **[La versión web](https://r3b0rnjhs.github.io/naruto-online-companion-web/)** |

### Instalarla en el móvil o en el Mac

Abre **[la versión web](https://r3b0rnjhs.github.io/naruto-online-companion-web/)** y:

- **Android (Chrome):** menú ⋮ → **Instalar aplicación** (o *Añadir a pantalla de inicio*).
- **iPhone (Safari):** botón Compartir → **Añadir a pantalla de inicio**.
- **Mac:** Safari → Archivo → **Añadir al Dock**; Chrome o Edge → el icono de instalar de la barra de direcciones.

Una vez instalada se abre como una app y funciona también sin conexión. Se actualiza sola cada vez que la abres con conexión.

### Tus datos

- Todo lo que apuntas se guarda **solo en ese dispositivo**, en el navegador. No hay cuentas ni servidores.
- Para pasar tus datos entre el PC y el móvil: *Ajustes → Copia de seguridad* (copias en uno y recuperas en el otro).
- No toca el juego: tú apuntas lo que tienes.
